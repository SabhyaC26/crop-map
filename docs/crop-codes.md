## Column names to use

| purpose | column | notes |
|---|---|---|
| Primary crop code | `MAIN_CROP` | **Primary crop code** chosen by Land IQ; one value per polygon, never null. Drives color/icon. |
| Other / multi-crop codes | `CROPTYP1`..`CROPTYP4` | Crop sequence for the polygon (see below). Codes equal to `MAIN_CROP` are the primary crop itself. |
| Multi-crop flag | `MULTIUSE` | `S` single, `D` double, `T` triple, `Q` quad. |
| Acres | `ACRES` | Polygon area in acres (`Shape_Area` is in square degrees; ignore it). |
| County | `COUNTY` | Title-case county name; `****` for polygons outside any county. |

Conventions in this file:

- All attribute columns except `ACRES`, `YR_PLANTED`, `ADOY*`, `MAIN_CROP_` and `Shape_*` are text.
- `****` is the null token for crop-code, `COUNTY`, `REGION` and `HYDRO_RGN` columns (`**` for `CLASS*`/`SUBCLASS*`/`PCNT*`, `*` for `SPECOND*`/`IRR_*`). There are no real nulls.
- A **code** is a legend class letter(s) plus an optional subclass number, e.g. `D12` = almonds, `T18` = miscellaneous truck, `V` = grapes (no subclass), `UL2` = urban golf course.
- `MAIN_CROP_` (trailing underscore) is **not** a code; it is an undocumented numeric field that looks like the approximate day-of-year of the main crop (range -92..273). Do not use it.
- `CLASS1..4`/`SUBCLASS1..4` split the same crop sequence into class letter and subclass (`CLASS2`/`SUBCLASS2` hold a single crop's class/subclass); `UCF_ATT` and `LIQ_REPORT` are Land IQ concatenations of these. Prefer the `CROPTYP*`/`MAIN_CROP` codes.

## Multi-crop columns explained

| value | meaning | polygons | total acres |
|---|---|---|---|
| `D` | double crop (two consecutive crops) | 22,807 | 689,843.7 |
| `Q` | quadruple crop (four consecutive crops) | 299 | 5,316.7 |
| `S` | single crop (one crop in the survey year) | 420,489 | 13,830,222.5 |
| `T` | triple crop (three consecutive crops) | 3,319 | 71,888.6 |

- Single-crop polygons (`MULTIUSE=S`): `CROPTYP1` is `****` for 99.7% of them and the crop sits in `CROPTYP2`.
- `MAIN_CROP == CROPTYP2` for 98.5% of polygons; `MAIN_CROP` equals some `CROPTYP*` value for 100.0%. `MAIN_CROP` is the **last** crop of the `CROPTYP1..4` sequence for 98.5% of polygons.
- **Caveat:** 3,316 polygons (76,756.3 acres, mostly orchards `D12`/`D13`/`C`) have `MAIN_CROP = 'X'` (unclassified fallow) only because a trailing `X` follows the real crop in `CROPTYP2/3`. When `MAIN_CROP` is `X` and a non-`X` code exists in `CROPTYP1..4`, the real crop is the last non-`X` code.
- 32,043 polygons list at least one `CROPTYP*` code different from `MAIN_CROP` (candidates for the popup's "also grown this year"); 36,251 polygons have two or more `CROPTYP*` set.
- Recommended pipeline mapping: primary = `MAIN_CROP`, except when it is `X` and a non-`X` code exists in `CROPTYP1..4` (then the last non-`X` code); `crop_ids_other` = the remaining distinct `CROPTYP1..4` codes (not `****`, not `X`) that differ from the primary.
